# 🏋️ Fitness Log

Turn training plans and completed workouts into structured Base rows. Say “bench press, 4 sets at 60 kg” in the App's Use chat; the Agent records date, exercise, sets, and weight. The log view shows sessions and the progress view summarizes maximum weight and daily set volume.

## Use it

1. Install the App and inspect the six sample rows.
2. Delete the `sample-*` rows before logging real workouts.
3. Open Use chat and describe a plan, completed workout, correction, or progress question.
4. Open Progress to review exercise records and volume.

Weight is stored in kilograms; bodyweight movements use `0`. Exercise names stay normalized so charts do not split one movement into multiple series.

## Requirements

None. The App uses AI Chat's built-in Base tools.
