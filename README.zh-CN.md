# 🏋️ 健身日志

## 这个 App 做什么

把训练计划和完成情况写成结构化日志。你在使用 chat 里说「卧推 4 组 60kg」，Agent 会记录日期、动作、组数和重量。训练记录页看流水，进展页看各动作最大重量与每日总组数。

## 怎么用

1. 安装后先查看 6 行示例数据。
2. 开始记真实训练前，删除 `sample-*` 示例行。
3. 在使用 chat 中描述计划、完成情况、修正或进展问题。
4. 切到「进展」页查看重量与训练量。

重量单位为 kg；自重动作写 `0`。同一动作保持统一名称，避免图表拆成多条序列。
